# GitHub Upload Checklist

- [ ] Extract the ZIP
- [ ] Create a GitHub repository
- [ ] Upload the files/folders
- [ ] Confirm `src/`, `public/`, `backend/`, and `package.json` are visible
- [ ] Commit to `main`
- [ ] Do not publish passwords, API keys, Sanity tokens or other secrets
- [ ] Add secrets through the deployment platform environment-variable settings
- [ ] Replace the placeholder sitemap domain after buying the final domain
- [ ] Migrate content to Sanity before switching away from the live AppDeploy backend
